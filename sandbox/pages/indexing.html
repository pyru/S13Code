Choosing an approximate index

HNSW builds a navigable small world graph and reaches high recall at modest memory cost, which makes it the default choice for corpora that fit in RAM. Its build time grows with the number of links kept per node, so an index that is cheap to query can still be expensive to construct.

When memory is tight

IVF partitions the vector space into cells and probes only the nearest ones. It uses markedly less memory than a graph index, but recall falls sharply when nprobe is set too low, so that single value deserves more tuning attention than the corpus size does.

Rebuilding after writes

An index is a rebuildable cache and never the source of truth. When the authoritative store changes, rebuild from the current authorised records rather than patching in place, because a partially patched index silently returns records that no longer exist.
